# GrapeLabStd

Сайт образовательной программы GrapeLab с разделами о направлениях, мероприятиях и VR-туре.

**Стек:** Python, Django, MySQL, HTML, CSS, JavaScript, Docker Compose, Nginx.

## Запуск

Установите зависимости из `requirements.txt`, задайте настройки окружения и запустите приложение Django. Для контейнерного запуска используйте `docker compose up --build`.
